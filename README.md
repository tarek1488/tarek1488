## Featured Work

### 🍽️ Bite — AI Calorie & Macro Tracker *(Founder & Developer)*
> **FastAPI · PostgreSQL · Supabase · Qdrant · OpenAI · Groq · Cohere · React Native (Expo) · Astro**

Say what you ate in English or Egyptian Arabic, and Bite turns it into a logged meal with calories and macros. Built solo, end to end: backend, iOS/Android app, and marketing site.

- Voice-to-meal AI pipeline: speech-to-text → structured LLM parsing → embedding search in Qdrant, with a batched LLM fallback for unknown foods
- Raised bilingual food-matching accuracy from **~73% to 97%** with dual named vectors (semantic + nutrition) and an alias layer
- Provider-agnostic modular monolith, Supabase Row-Level Security with column-level grants, server-verified RevenueCat subscriptions

📱 [Download on the App Store →](https://apps.apple.com/us/app/bite-calorie-macro-tracker/id6812544804)

### 🎥 OC Meet — Multi-Tenant SaaS Meetings *(Product Engineer @ OverClick)*
> **Next.js · TypeScript · PostgreSQL · Prisma · Redis · BullMQ · LiveKit · Docker**

A multi-tenant meeting platform built from architecture to production, bilingual English/Arabic (RTL).

- Isolated workspaces with per-tenant branding, Keycloak OIDC SSO, and auto-provisioned custom domains
- Real-time meetings on LiveKit (WebRTC) with server-enforced plan limits
- Payments built correct-first: idempotent webhooks, an audited subscription state machine, and a self-healing reconciliation worker
- Operator console with RBAC and a full audit trail · Prometheus/Grafana monitoring · load and concurrency testing

🌐 [Visit ocmeet.sa →](https://ocmeet.sa)
